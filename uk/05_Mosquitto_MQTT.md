# Home Assistant на Android із нативним chroot: 05 — Брокер Mosquitto MQTT (необов’язково)

Англійська версія: [05_Mosquitto_MQTT.md](../05_Mosquitto_MQTT.md).


Якщо потрібна локальна служба MQTT, налаштуйте брокер Mosquitto у Termux. Цей крок необов’язковий; його можна виконати до ввімкнення брокера на [кроці 06](06_Automatic_Startup.md).

## Налаштування локального брокера Mosquitto (необов’язково)

Виконуйте цей розділ, лише якщо потрібен **локальний брокер MQTT**. Якщо HA підключається до наявного мережевого брокера або MQTT не використовується, пропустіть його.

Спочатку встановіть Mosquitto та створіть каталоги конфігурації:

```sh
pkg install -y mosquitto
mkdir -p ~/.config/mosquitto ~/.local/share/mosquitto
chmod 700 ~/.config/mosquitto ~/.local/share/mosquitto
```

Далі інтерактивно створіть файл паролів для користувача `homeassistant`:

```sh
mosquitto_passwd -c ~/.config/mosquitto/passwd homeassistant
```

На запит введіть і підтвердьте пароль. Потім відредагуйте файл конфігурації:

```sh
nano ~/.config/mosquitto/mosquitto.conf
```

Вставте цю конфігурацію, щоб брокер приймав підключення з телефона й локальної мережі. Пристрої, підключені через той самий роутер, зможуть звертатися до брокера за LAN-адресою Android-хоста. Прослуховування `0.0.0.0` потрібне для цього; не налаштовуйте перенаправлення портів на роутері, яке відкриє порт 1883 в Інтернет.

> **Безпека:** MQTT на порту 1883 не шифрує ім’я користувача й пароль. Використовуйте таке налаштування лише в довіреній LAN. Для доступу поза цією мережею використовуйте VPN або налаштуйте TLS.

```conf
persistence true
persistence_location /data/data/com.termux/files/home/.local/share/mosquitto/

log_dest file /data/data/com.termux/files/home/.local/share/mosquitto/mosquitto.log

# Слухати на всіх інтерфейсах IPv4 для доступу з LAN; лише для телефона вкажіть 127.0.0.1
listener 1883 0.0.0.0

# Заборонити підключення без пароля
allow_anonymous false
password_file /data/data/com.termux/files/home/.config/mosquitto/passwd
```

Для початкової діагностики за бажанням запустіть брокер у передньому плані в **сеансі Termux 1**:

```sh
mosquitto -c ~/.config/mosquitto/mosquitto.conf -v
```

Залиште брокер запущеним. У **сеансі Termux 2** запустіть підписника; параметр `-C 1` означає, що він чекатиме на одне повідомлення:

```sh
mosquitto_sub -h 127.0.0.1 -p 1883 -u homeassistant -P '<password>' -t test/topic -C 1
```

Поки підписник очікує, надішліть тестове повідомлення з **сеансу Termux 3**:

```sh
mosquitto_pub -h 127.0.0.1 -p 1883 -u homeassistant -P '<password>' -t test/topic -m ok
```

Коли підписник отримає `ok`, зупиніть брокер клавішами `Ctrl+C` у сеансі 1. Ці діагностичні команди перевіряють брокер із цього самого телефона за адресою `127.0.0.1`.

У меню **Settings → Devices & services → Add integration → MQTT** (у локалізованому інтерфейсі: **Параметри → Пристрої та служби → Додати інтеграцію → MQTT**) вкажіть:

```text
Брокер: 127.0.0.1
Порт: 1883
Ім’я користувача / пароль: дані для входу, створені вище.
```

Для Home Assistant на цьому телефоні використовуйте `127.0.0.1`, як у прикладі. Клієнти на інших пристроях LAN мають використовувати LAN-адресу Android-хоста (наприклад, `192.168.31.2`; у вас вона може відрізнятися).
