# Home Assistant на Android із нативним chroot: 01 — Підготовка пристрою

Англійська версія: [01_Device_Preparation.md](../01_Device_Preparation.md).


У цьому посібнику використовується нативний `chroot` на Android із root-доступом, а не `proot`. Нативний chroot корисний, коли потрібен прямий доступ до мережі, USB, Bluetooth або SD-картки. Помилка під час прошивання чи форматування може призвести до втрати даних або зробити телефон нездатним завантажитися.

## Перевірена конфігурація

Перевірений пристрій — **Xiaomi Redmi Note 8T** із Snapdragon 665, 4 ГБ оперативної пам’яті, 64 ГБ сховища, розблокованим завантажувачем, LineageOS і Magisk. Назви пристроїв Xiaomi та кодові назви прошивок легко переплутати. Перед завантаженням recovery, прошивки або ROM звірте **точну модель і кодову назву** з джерелом для потрібної збірки. Ніколи не прошивайте файли, підібрані лише за схожою назвою телефона. Нові версії HA можуть не працювати на 32-бітних ROM через обмеження `cryptography`.

Після встановлення Termux перевірте архітектуру процесора:

```sh
getprop ro.product.cpu.abi
```

Очікуваний результат:

```text
arm64-v8a
```

```sh
uname -m
```

Очікуваний результат:

```text
aarch64
```

Після встановлення занотуйте в issue або README:

- модель, кодову назву, обсяг оперативної пам’яті та сховища;
- версію Android / LineageOS і дату збірки;
- версію прошивки;
- версії Magisk, `chroot-distro` і BusyBox NDK;
- версії Home Assistant і Python;
- чи використовується SD-картка та яку файлову систему вона має.

## Що знадобиться

- ПК із робочими `adb` і `fastboot`, який розпізнає телефон.
- Надійний USB-кабель і заряд акумулятора щонайменше 60%.
- Резервна копія всіх даних телефона. Розблокування завантажувача та форматування `data` стирають дані.
- Офіційний посібник зі встановлення, recovery та прошивка для точної версії LineageOS.
- SD-картка, якщо вона потрібна. Її форматування на кроці 04 **стирає всі дані**.
- Для USB-пристроїв на кшталт Zigbee- чи Ethernet-адаптерів потрібен USB-C-концентратор із Power Delivery (PD), щоб одночасно живити телефон і використовувати периферійні пристрої.
- Для стабільного запуску chroot часто потрібно перевести SELinux у permissive-режим (`setenforce 0` від root під час завантаження). Врахуйте цей компроміс безпеки: не використовуйте телефон із root-доступом для банківських застосунків чи чутливих особистих даних і не відкривайте SSH, MQTT або вебінтерфейс Home Assistant у недовірених мережах.

## Послідовність прошивання

Для Xiaomi Redmi Note 8T використовуйте [офіційні збірки](https://download.lineageos.org/devices/ginkgo/builds) і дотримуйтеся [офіційного посібника зі встановлення](https://wiki.lineageos.org/devices/ginkgo/install/variant2/).

Нижче наведено скорочений опис. Увійдіть у режим Fastboot, затиснувши **зменшення гучності + живлення**, а потім відкрийте командний рядок або термінал на ПК у каталозі `flashing`.

Спочатку переконайтеся, що Fastboot бачить пристрій:

```sh
cd C:\flashing 
fastboot devices
```

Якщо пристрій відображається у списку, прошийте образи розділів:

```sh
fastboot flash vbmeta vbmeta.img
fastboot flash dtbo dtbo.img
fastboot flash boot boot.img
fastboot flash recovery recovery.img
```

У Lineage Recovery виберіть **Apply update → Apply from ADB** (на екрані з’явиться повідомлення “Now send the package…”). Потім перевірте ADB-з’єднання з ПК:

```sh
adb devices
```

Прошивку, ROM і пакети для root-доступу потрібно надсилати послідовно. Перед кожною командою `adb sideload` на ПК у Lineage Recovery знову виберіть **Apply update → Apply from ADB**:

1. У recovery виберіть **Apply update → Apply from ADB**, потім виконайте:

```sh
adb sideload fw.zip
```

2. Після завершення sideload знову виберіть **Apply update → Apply from ADB**, потім виконайте:

```sh
adb sideload lineage.zip
```

3. Ще раз виберіть **Apply update → Apply from ADB**, потім виконайте:

```sh
adb sideload magisk.zip
```

## Перш ніж продовжити

Переходьте до [кроку 02](02_Android_Config_Termux.md), лише якщо виконано всі умови:

```text
[ ] Android завантажується без циклічного перезавантаження.
[ ] Magisk підтверджує робочий root-доступ.
[ ] Wi-Fi підключається, телефон має доступ до Інтернету.
[ ] Root-доступ зберігається після перезавантаження.
[ ] Ви знаєте, як увійти в recovery і Fastboot та як відновити пристрій.
```
